## Publication gate

Статьи и их маршруты готовы как Markdown-корпус, но массовая публичная
активация продуктовой автоматики пока **NO-GO**:

1. нужно подтвердить рабочий публичный `/test-arhetipov/`;
2. на посадочной менторинга нужно заменить категоричные гарантии результата
   на негарантирующий язык;
3. HTML должен показывать продукт только после
   `safety_normal + product_interest + product_active + audience_fit`;
4. для Telegram ещё нужны token service, privacy-safe handoff и единый
   recommendation runtime.

При невыполнении gate продуктовый блок скрывается без автоматической подмены
другим продуктом. Даты, цены и статус набора остаются на продуктовых страницах,
а не в evergreen-статьях.
