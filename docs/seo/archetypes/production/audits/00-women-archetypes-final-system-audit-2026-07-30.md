## Единая маршрутизация

Для всех восьми страниц машинная матрица теперь совпадает с фактическим
текстом:

```text
page_safety_class = standard
next_intent = mentoring
destination = /mentoring/
```

В каждом Markdown-файле:

- ровно один продуктовый CTA на `/mentoring/`;
- ровно одна ссылка на `/zhenskie-arhetipy/`;
- нет ссылок на `/test-arhetipov/`;
- есть от двух до трёх контекстных ссылок на соседние ролевые статьи.

Поэтому публичный маршрут одинаков по логике, но не механически одинаков по
тексту:

```text
поиск / карта / Telegram
→ конкретная ролевая статья
→ самостоятельное узнавание или практика
→ менторинг «Высокая Глубина»
```

Индивидуальная работа, онлайн-неделя и ретрит не используются как CTA этих
восьми ролевых страниц.
