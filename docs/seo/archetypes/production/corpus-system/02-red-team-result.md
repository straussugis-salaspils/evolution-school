## REOPEN P0 — внешнее подтверждение заявки

На стороне статического сайта прослеживается путь:

`article_view → product_click → lead_start`.

Событие `lead_submit` и его атрибуция реализованы для собственной формы или
фактического `eh:lead-success`, но текущие конечные действия происходят вне
сайта:

- GetCourse для менторинга;
- Stripe для недель;
- Telegram для ретрита.

Ни одна из этих систем сейчас не возвращает сайту подтверждённый success.
Поэтому красная команда не разрешает считать обычный исходящий клик
`lead_submit`.

Условие закрытия: настроить callback/postback, thank-you URL, cross-domain
measurement или webhook хотя бы для каждого коммерчески значимого внешнего
пути и показать trace с одинаковыми `route_id`, `product_id`, `cta_variant`,
`placement`. Это требует доступа к внешним кабинетам или отдельного решения о
собственной форме/success page.
